## 0. Why this batch, right now

A separate concurrent session is actively driving the B1 grammar sequence proper — batches 11–13
(derived verb forms, relative clauses) are merged, and batch 14 (إنّ وأخواتها) is open as a scope
draft ([PR #49](https://github.com/djkm1208alt/arabic/pull/49)), with batch 13's own §8 already

full 4–6-unit B1 grammar document now — the original ask — would mostly re-describe work already
merged or already claimed by name.

This batch instead targets the one piece of the audit's own recommendation that is **completely
untouched by any batch, branch, or scope doc anywhere in the repo** (confirmed by direct search
before authoring, §2), **needs zero new grammar and zero new lexemes**, and **finally exercises the

not compete with the other session's batch 11–15 sequence — none of those touch the `parse` field,
the `label` exercise type, or any of the seven A1/A2 texts this batch reuses.

## 1. What this batch covers

Formally naming five grammatical roles learners already use correctly, without the metalanguage,
by A2: **مُبْتَدَأ** (mubtadaʾ), **خَبَر** (khabar), **فَاعِل** (fāʿil), **مَفْعُول بِهِ** (mafʿūl
bih), **مُضَاف إِلَيْهِ** (muḍāf ilayhi) — exactly the five roles `LABEL_ROLES` already defines in
`index.html` (M21.6). Practice runs on seven sentences already sitting in `content/texts.json` as
examples for `gr:nominal-sentence`, `gr:verbal-sentence`, and `gr:idafa` — no new sentences, no new
words, just the mechanism finally pointed at content that already exists.

**Not full iʿrāb.** No case (رفع/نصب/جر) — every `parse` entry this batch authors omits `case`
entirely, which is what keeps a `label` item in the engine's own "role-only" tier (M21.6 §4.2/§4.5).
Full role+case parsing stays `b2-u1`'s job, per the audit and per `CURRICULUM_ARCHITECTURE.md`.

## 2. Checked before authoring

- **`grep -rn '"parse"' content/texts.json` returns nothing** — the mechanism is still exactly as
  dormant as M21.6 left it, confirmed fresh against the current `main`, not assumed from memory.
- **No open branch, PR, or scope doc anywhere touches `parse`, `label`, or `exerciseTypes.label`** —
  checked via `git ls-remote` against every remote branch and the two currently-open PRs (#49, an
  unrelated stale #19). Batches 11–14 are derived verb forms, relative clauses, and إنّ وأخواتها —
  orthogonal grammar, orthogonal texts.
- **The five roles are not just "functionally known" — the exact Arabic terms already sit in the
  app's own rule text**, unused as a practice target until now: `gr:nominal-sentence` (A1) names
  "topic (mubtadaʾ)" and "comment (khabar)" directly in its `rule` string; `gr:verbal-sentence` (A2)
  names فَاعِل and مَفْعُول in its own VSO explanation; `gr:idafa` (A2) names مُضَاف and مُضَاف
  إِلَيْهِ in its own rule. This is the audit's "PP" (already taught) classification confirmed
  against the actual shipped rule text, not inferred.
- **Traced the exact schema a `label` item needs**, reading `exerciseTypes.label`/`exGenLabel` in
  `index.html` directly rather than assuming: a literal step object with `sentenceHtml` (target word
  wrapped in `<mark class="label-target">…</mark>`), `options` (`{key, ar, en}[]`), and `answer`.
- **Confirmed `tools/build-content.js`'s `fromObjectives` expansion only supports `exercise.kind ===
  "build"`** (hard-coded in both its validator and its compiler, read directly). Rather than extend
  the build tool to add a second generic path — real code, and this batch's whole point is to ship
  on the existing mechanism with zero engine change — this batch authors literal `exercise: {kind:
  "label", …}` step objects directly, exactly the same hand-authored-literal-options pattern every
  `practice-choice` step in every prior batch already uses. Zero lines of `index.html` or
  `tools/*.js` change.
- **Picked one unambiguous target word per role, and only sentences where the traditional grammar
  isn't debatable.** E.g. `أَنَا قَرَأْتُ الْكِتَابَ` is used for مفعول به (الْكِتَابَ, unambiguous)
  but *not* for فاعل — the free pronoun أَنَا there is not itself the classical fāʿil (a hidden
  pronoun bound to the verb ending is); `ذَهَبَ الرَّجُلُ` is used for فاعل instead, where the
  subject is an explicit, undebatable noun.
